# AntiqueAuction — Antique Auction Platform
**Task ID:** WD-AUC-005 | **Student Code:** DAS-AUC-005 | **Company:** Data Alcott Systems

Responsive frontend-only vintage collectibles auction demo built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Antique listings with search and category, era and condition filters
- Item detail popup with age, origin, condition and illustrative provenance
- Simulated expert valuation
- Demo bidding room with countdown and minimum-bid validation
- Collector watchlist and bid history stored in localStorage
- CSV export, sample authenticity certificate check, dark mode and responsive layout

## Run locally
Open `index.html` in a browser, or use VS Code Live Server. No database, package installation or build step is required.

## Demo limitations
Authentication, valuation, provenance, certificate verification and bidding are simulated. Data stays in the current browser. There is no backend, real-time multi-user bidding, payment processing or independent antique authentication.

## Technologies
HTML5 · CSS3 · JavaScript · localStorage
